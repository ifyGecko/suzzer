suzzer coverage-formula conformance vectors
============================================

Generated by test/gen_vectors.sh from src/sink.h (the code libcov runs), so
they show exactly what libcov's sink_emit produces. Do not edit by hand:
`make vectors` regenerates them, and `make test` fails if they no longer
match the runtime. The formula itself is specified in docs/FORMATS.md
("Coverage bucket formula").

One directory per vector: <model>_n<N>_r<R>_<map_size>/

  model     site (site-id model) or pc (hashed-PC model)
  N         N-gram length: 1, 2, 3, 4, 8
  R         rotation off (0) or on (1)
  map_size  4096, 65536, 1048576

  scheme.json   the parameters, plus values derived from them (map_bits and
                rot_amounts with rotation; module_bases for the PC model;
                lcvs_scheme_flags = the LCVS header bits for this scheme;
                counts of emits/resets/nonzero/saturated buckets)
  sequence.bin  the emits, little-endian, back to back:
                  site: u32 site_id
                  pc:   u64 pc, u8 module_idx            (9 bytes each)
                the all-ones record (site: ffffffff; pc: ff x 9) resets the
                N-gram history, as an iteration boundary does
  expected.bin  the bitmap (map_size bytes of saturating uint8 counters)
                after replaying sequence.bin into a zeroed map from a
                zeroed history

map_size.jsonl: one JSON object per N (1..8) giving the map size the
site-id model picks for a list of site counts ("sizes": [[n_sites,
map_size], ...]) with that N's default LIBCOV_MAP_FUDGE.

An implementation is "scheme-compatible" when, for every vector of the
scheme(s) it claims, replaying sequence.bin gives expected.bin byte for
byte. test/vectors_check.py is an independent Python implementation that
does exactly that.

A consumer may vendor only the directories for the schemes it claims (plus
this README and map_size.jsonl); most of the 25 MB is the 1 MiB maps.
